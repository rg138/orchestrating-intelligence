### Quick start

1. Select **Code → Download ZIP** from the repository's main page.
2. Extract the archive and open a terminal in the extracted folder.
3. Run `python delivery_evidence.py --self-test` (Python 3.10 or newer).
4. Run `python delivery_evidence.py --output my-demo` to generate example output.

The examples are instructional. Do not point them at real confidential or production records without appropriate review and authorization.
